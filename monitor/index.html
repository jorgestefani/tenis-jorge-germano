Como criar o token
GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate. Em "Repository access" escolha só tenis-jorge-germano. Em "Permissions → Repository" deixe Contents: Read and write e Actions: Read and write. Copie e cole acima.
